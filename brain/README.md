# Product documentation

`index.html` is the complete, self-contained Product Requirements Document for
**GeM Tender Brain**. Open it in any browser — no server, build step or network
connection is needed.

It covers:

- product overview, goals, users and scope
- the seven-stage pipeline and system architecture
- functional requirements, filtering rules and the scoring model
- data model, API reference and configuration
- setup, Google Sheets, interface guide, CLI and scheduling
- quality evidence, risks, roadmap, FAQ and glossary

The application code lives in the project root (`backend/`, `frontend/`, `tests/`);
see `../README.md` for the short operational guide.
